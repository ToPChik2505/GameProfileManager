## О программе

Game Profile Manager применяет индивидуальные игровые настройки через **RivaTuner Statistics Server (RTSS)** и **NVIDIA Driver Profile Settings (DRS)**. Он позволяет ограничивать FPS, выбирать параметры синхронизации и назначать профиль исполняемому файлу игры. После применения программа повторно считывает значения и сохраняет исходные настройки для последующего восстановления.

Игры по-прежнему запускаются через Steam, Epic Games Launcher, ярлыки или обычные `.exe`. Game Profile Manager **не запускает игры** и не ведёт статистику игрового времени.

## Возможности

- **Профили для отдельных игр:** лимит FPS, режим G-SYNC/фиксированной частоты NVIDIA, V-Sync и режим лимитера RTSS.
- **Назначение по мониторам:** один профиль на игру или разные профили в зависимости от выбранного дисплея Windows.
- **Автоматическая проверка конфигурации:** реакция на подтверждённое изменение дисплеев; необязательная проверка и повторное применение при запуске.
- **Импорт Steam и Epic Games:** обнаружение установленных игр с возможностью вручную выбрать подходящий `.exe`.
- **Контроль применения:** повторное чтение параметров, сохранение исходных значений RTSS/NVIDIA и попытка отката при ошибке.
- **Интерфейс Windows 11:** WinUI 3, системные светлая и тёмная темы, Mica, адаптивная навигация.
- **Управление геймпадом:** SDL3, поддержка контроллеров Xbox и PlayStation, файловый браузер и экранная клавиатура.
- **Трей и диагностика:** работа при скрытом окне, проверка подключений и поиск расхождений в настройках.

> [!NOTE]
> Раздел **«Графические конфигурации»** пока демонстрирует планируемую функцию. Сохранение, назначение и применение снимков файлов конфигурации игры **ещё не реализованы**.

## Системные требования

| Компонент | Требование |
| --- | --- |
| Операционная система | **Windows 11 x64** |
| Видеокарта и драйвер | NVIDIA с совместимым драйвером и поддержкой NVIDIA DRS |
| Ограничение FPS | Установленный и запущенный **[RivaTuner Statistics Server (RTSS)](https://www.guru3d.com/download/rtss-rivatuner-statistics-server-download/)** |
| Права доступа | Подтверждение прав администратора при запуске текущей версии программы |
| Среды выполнения | Включены в установщик (.NET 10, Windows App SDK и SDL3) |

Для использования G-SYNC его нужно отдельно включить в **Панели управления NVIDIA**. Game Profile Manager управляет профилем конкретной игры, но не активирует G-SYNC глобально.

## Установка

1. Скачайте актуальный установщик в разделе **[GitHub Releases](https://github.com/Vladislav2505/GameProfileManager/releases)**.
2. Установите RTSS, обновите драйвер NVIDIA и запустите RTSS.
3. Установите и откройте **Game Profile Manager**, подтвердив запрос Windows на права администратора.
4. Если RTSS не обнаружен, откройте **«Настройки»** и выберите папку установки RTSS.

Установщик содержит необходимые компоненты. Отдельно устанавливать .NET Runtime или Windows App SDK не нужно. Программа создаёт ярлык в меню «Пуск»; ярлык на рабочем столе можно выбрать при установке.

**Обновление с версии 1.x:** в версии 2.0 интерфейс перенесён с WPF на WinUI 3, но структура базы и формат профилей сохранены. Перед обновлением полностью завершите приложение, включая значок в трее. Данные в `%LOCALAPPDATA%\GameProfileManager` сохраняются.

## Быстрый старт

1. Откройте **«Мои игры»** и импортируйте библиотеку Steam/Epic Games либо добавьте `.exe` вручную.
2. Проверьте исполняемый файл: у некоторых игр есть отдельный лаунчер или несколько `.exe`.
3. В разделе **«Профили»** выберите готовый набор или **создайте его редактируемую копию**. Встроенные профили защищены от изменений.
4. Откройте нужную игру, назначьте профиль и нажмите **«Применить профиль к игре»**. Команда **«Применить ко всем»** последовательно обработает библиотеку.
5. Проверьте результат и при необходимости воспользуйтесь **«Диагностикой»**: она позволяет прочитать параметры без их изменения.

**Назначение профиля** изменяет конфигурацию внутри программы. **Применение профиля** записывает настройки в RTSS и NVIDIA DRS. Это разные действия. Автоматическая запись также возможна при включённых настройках, например после обнаружения изменения конфигурации мониторов или во время проверки при запуске.

### Статусы применения

| Статус | Значение |
| --- | --- |
| **Применён** | RTSS и NVIDIA DRS при повторном чтении подтвердили ожидаемые параметры. |
| **Ожидает** | Назначенные параметры ещё не подтверждены как применённые. |
| **Требуется перезапуск** | Параметры записаны, но уже запущенную игру может понадобиться перезапустить. |
| **Недоступно** | Не выполнено необходимое условие либо конфигурацию нельзя безопасно определить. |
| **Ошибка** | Применение или проверка завершились неудачно; причина доступна в карточке игры. |

## Профили и мониторы

Лимит FPS задаётся **числом от 1 до 1000** либо **долей частоты монитора от 1/1 до 1/12**. Расчёт по доле доступен, только когда можно определить поддерживаемый целочисленный FPS. Динамическая частота обновления Windows блокирует этот способ расчёта.

Дополнительные настройки: режим монитора NVIDIA (G-SYNC или фиксированная частота), V-Sync и режим лимитера RTSS. В качестве FPS-лимитера программа использует RTSS, а управляемое ограничение NVIDIA отключает (`FRL_FPS = 0`) при применении профиля.

Если для выбранного профиля не удаётся рассчитать FPS из-за отсутствующего монитора, динамической частоты или неделимого значения, **«Применить» оставляет настройки RTSS/NVIDIA и резервную копию без изменений**. Для возврата к исходным значениям используйте явное действие **«Восстановить прежние параметры»**.

### Режим назначения

| Режим | Поведение |
| --- | --- |
| **Один профиль** | Игра использует один профиль. При расчёте FPS по доле частоты результат по-прежнему может зависеть от выбранного монитора. |
| **По монитору** | Можно назначить каждому дисплею свой профиль. Если отдельное назначение отсутствует, используется основной профиль игры (если задан). |

При выборе режима **«По монитору»** доступно правило определения экрана:

| Правило | Как выбирается монитор |
| --- | --- |
| **Основной экран Windows** | Дисплей, указанный как основной в параметрах Windows. |
| **Выбранный экран, иначе общий** | Экран игры; если он не выбран — общий дисплей приложения, затем основной экран Windows. |
| **Только выбранный экран** | Требуется явно выбранный дисплей. При отключении автоматическая подмена не выполняется. |

Программа периодически проверяет конфигурацию дисплеев, включая работу в трее. **Она не определяет, на каком мониторе открыто окно игры**, и не изменяет разрешение, герцовку или HDR средствами Windows.

## Безопасность, резервные копии и диагностика

Перед первым изменением настроек игрового `.exe` программа сохраняет исходные значения RTSS и NVIDIA DRS. Если удалось выполнить только часть операции, предпринимается попытка отката. После записи выполняется повторное чтение настроек.

- **«Проверить сейчас» / «Диагностика»** — чтение параметров без их исправления.
- **«Восстановить прежние параметры»** — возврат сохранённых значений; после успешного восстановления программа также может снять назначения профилей с игры.
- **Экспорт резервной копии** в настройках — сохранение JSON-копии конфигурации приложения.
- **Смена EXE:** если для прежнего файла есть резервные значения, сначала выполняется попытка восстановления старых параметров.

**Что означает успешная проверка:** RTSS и NVIDIA DRS сообщили ожидаемые значения. Это **не** измерение фактического FPS и не гарантия включения VRR непосредственно в игре.

> [!IMPORTANT]
> Game Profile Manager изменяет внешние игровые профили. По возможности закрывайте игры перед записью драйверных настроек и храните резервную копию конфигурации. Для восстановления исходных значений RTSS может потребоваться запущенный RTSS.

## Геймпад и системный трей

Ввод реализован через SDL3. Программа показывает обозначения Xbox или PlayStation (включая DualSense) в зависимости от контроллера.

| Кнопки | Действие |
| --- | --- |
| Крестовина / левый стик | Перемещение фокуса |
| A / ✕ | Выбор или подтверждение |
| B / ○ | Назад или закрытие раскрытого списка |
| Start / Options | Открыть или закрыть боковое меню; диалоги, файловый браузер и экранная клавиатура имеют приоритет |
| LB / RB · L1 / R1 | Переключение основных разделов |
| Триггеры / правый стик | Прокрутка |
| Экранная клавиатура | Ввод текста без физической клавиатуры |

В **«Настройках»** можно включить сворачивание в трей и автозапуск с Windows. При работе в трее отслеживание дисплеев продолжается. Полный выход доступен через контекстное меню значка.

Интерфейс учитывает масштабирование дисплеев Windows (Per-Monitor V2 DPI) и системную тему; также можно вручную выбрать Light или Dark. Минимальный размер окна в текущей версии — **420 × 560 эффективных пикселей**. На узкой ширине карточки, строки игр, детали профиля и кнопки действий располагаются вертикально; длинные страницы прокручиваются. Системные кнопки заголовка сохраняются.

## Обновления и пользовательские данные

- **Обновления:** **«Настройки → Резервные копии и обновления → Проверить обновления»**. Проверка последнего GitHub Release выполняется по запросу. Скачивание и установка новой версии — вручную.
- **База данных:** `%LOCALAPPDATA%\GameProfileManager\profiles.db` — SQLite с одним JSON-документом состояния, назначениями и исходными параметрами.
- **Журнал ошибок:** `%LOCALAPPDATA%\GameProfileManager\errors.log`.
- **Экспорт:** резервные JSON-файлы сохраняются в каталоге данных приложения.
- **Совместимость:** версия 2.0 сохраняет данные 1.x. Повреждённая/нечитаемая база не заменяется автоматически пустым состоянием.

Необязательная настройка **«Запуск с повышением без повторного UAC»** использует задачу Планировщика Windows. Для её включения нужны права администратора и установка приложения в защищённую папку `Program Files`; проверяются путь EXE, владелец и ACL. Задача не принимает аргументы от запускающего пользователя; автозапуск может по-прежнему потребовать UAC. Загрузка DLL RTSS также допускается только из защищённой установки в `Program Files`. Если выбранная папка RTSS доступна обычному пользователю для записи, DLL блокируется до загрузки.

## Ограничения

- **Только NVIDIA и RTSS:** профили драйверов других производителей не поддерживаются.
- **Не лаунчер:** нет запуска игр, учёта игрового времени или управления версиями игр.
- **Не переключает параметры Windows:** разрешение, герцовка, HDR и топология дисплеев не изменяются.
- **Не измеряет FPS/VRR в игре:** повторное чтение подтверждает сохранённые настройки, а не фактическую производительность.
- **Совпадающие имена EXE:** RTSS сопоставляет игровые профили по имени файла; программа блокирует неоднозначную запись для разных игр с одинаковым именем `.exe`.
- **Снимки графических файлов пока не реализованы.**

## Решение проблем

**RTSS не обнаружен или закрыт.** Убедитесь, что RTSS установлен и запущен, затем укажите его каталог в **«Настройках»**. Если доступна кнопка **«Запустить RTSS»**, нажмите её и повторно проверьте игру. Сам запуск RTSS не означает автоматического применения профиля.

**У игры статус «Ожидает» или «Недоступно».** Проверьте выбранный `.exe`, назначенный профиль, режим монитора и подключения в **«Диагностике»**. Для динамической или неподдерживаемой частоты может не получиться рассчитать лимит FPS по доле.

**Требуется перезапуск игры.** Параметры драйвера NVIDIA могут не повлиять на уже запущенный процесс. Закройте игру, запустите снова и проверьте настройки.

**У нескольких игр одинаковое имя EXE.** RTSS использует имя файла для сопоставления профилей. По возможности выбирайте разные исполняемые файлы; программа намеренно блокирует неоднозначную запись.

Если проблему можно повторить, создайте [Issue](https://github.com/Vladislav2505/GameProfileManager/issues).

## Сборка из исходников

**Потребуется:** Windows 11, [.NET SDK 10](https://dotnet.microsoft.com/download/dotnet/10.0) и, если нужен установщик, [Inno Setup](https://jrsoftware.org/isdl.php). Зависимости Windows App SDK устанавливаются через NuGet при восстановлении проекта.

```powershell
# Из корня репозитория
dotnet build .\GameProfileManager.slnx -c Release

# Модульные проверки (без записей в реальные RTSS/NVIDIA)
dotnet run --project .\tests\GameProfileManager.Tests -c Release

# Интеграционные проверки (по умолчанию только чтение)
dotnet run --project .\tests\GameProfileManager.IntegrationTests -c Release

# UI Smoke с тестовыми клиентами интеграций и временным состоянием
$smoke = Join-Path .\artifacts ("ui-smoke-" + [guid]::NewGuid().ToString("N"))
dotnet run --project .\tests\GameProfileManager.UITests -c Release -- $smoke
```

UI Smoke требует интерактивного рабочего стола Windows. **Не запускайте** интеграционные режимы `--write-test`, `--nvidia-write-test` и `--sync-test` с настоящими RTSS/NVIDIA, если не планируете намеренно изменять настройки.

Публикация автономной сборки без упаковки:

```powershell
dotnet publish .\src\GameProfileManager\GameProfileManager.csproj `
  -c Release -r win-x64 --self-contained true `
  -p:WindowsAppSDKSelfContained=true `
  -p:PublishSingleFile=false -p:PublishTrimmed=false `
  -o .\artifacts\test-exe
```

Запускайте `GameProfileManager.exe` из **полной папки публикации**. Недостаточно скопировать один EXE: требуются `GameProfileManager.pri`, библиотеки Windows App SDK и SDL3.

Для создания установщика (Inno Setup 6/7):

```powershell
.\scripts\build-installer.ps1
```

Результат появится в `artifacts\installer`. При необходимости укажите путь к компилятору через `-InnoCompiler`.

### Структура проекта

```text
GameProfileManager.slnx
src/
  GameProfileManager/          # WinUI 3, ввод, трей и исходные модули
    Core/                     # Доменные модели
    Application/              # Синхронизация и выбор профилей
    Infrastructure/           # Хранение SQLite
    Integrations/             # NVIDIA, RTSS, Steam/Epic, мониторы
    Native/                   # SDL3 и лицензия
    Assets/                   # Значки приложения
  GameProfileManager.Engine/   # Отдельная сборка Engine с подключёнными модулями
tests/                       # Модульные, интеграционные, UI Smoke проверки
installer/                   # Сценарий Inno Setup
scripts/                     # Сборка установщика и замеры производительности
.github/workflows/           # CI проверок и сборки установщика Windows
```

Файлы `Core`, `Application`, `Infrastructure` и `Integrations` физически находятся в `src/GameProfileManager`, но компилируются в отдельную сборку `GameProfileManager.Engine` через связанные исходные файлы проекта.

### Выпуск новой версии

[Workflow установщика](.github/workflows/installer.yml) проверяет Release-сборку x64, изолированные проверки с подставными клиентами RTSS/NVIDIA и SQLite, а также ресурсы WinUI в PR, `main` и тегах `v*`. Сборка установщика начинается только после этих проверок; UI Smoke требует отдельного интерактивного сеанса Windows. Для выпуска измените `<Version>` в `src/GameProfileManager/GameProfileManager.csproj`, отправьте коммит и соответствующий тег (например, `v2.0.0`). Workflow опубликует собранный установщик в GitHub Releases.
