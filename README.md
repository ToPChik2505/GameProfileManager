# Game Profile Manager — актуальная сборка

Дата: 19 октября 2026 года.

- `GameProfileManager-win-x64.zip` — готовое приложение. Распакуйте архив целиком и запустите `GameProfileManager.exe` из папки `GameProfileManager-win-x64-2026-10-19`.
- `GameProfileManager-source.zip` — исходный код и тестовые проекты.
- `GameProfileManager-preview-games.png`, `GameProfileManager-preview-profiles.png`, `GameProfileManager-preview-status-menu.png`, `GameProfileManager-preview-vrr-menu.png` и `GameProfileManager-preview-vsync-menu.png` — снимки обновлённой таблицы и переведённых меню.

В этой версии добавлены отступы таблицы, русские статусы, русские названия предустановленных профилей и русские подписи режимов VRR/V-Sync. Существующие профили с исходными английскими названиями переименовываются при открытии приложения.

Каталог `GameProfileManager-win-x64` без даты содержит прежнюю версию, которую Windows не дала заменить, пока она открыта. Используйте датированную папку или свежий архив.
